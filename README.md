# Fynnsera — AI-Powered Fintech App
Live Link: https://fynsera.netlify.app/

> Smart transaction insights with 99% accurate AI-driven categorization.

## Overview
Fynnsera is a full-stack AI fintech application that analyzes and categorizes user transactions with industry-leading precision. It helps users gain personalized financial insights through clean, responsive dashboards and natural language interactions.

## Features
-  **AI-Powered Transaction Categorization** (99%+ accuracy)
-  **Spending Insights & Trends**
-  **Chat With Your Finances** using LangChain + OpenAI
-  **Firebase Authentication**
-  **Dark Mode & Responsive UI**

## 🛠 Tech Stack

| Layer        | Technologies                            |
|--------------|------------------------------------------|
| Frontend     | Next.js, TailwindCSS                   |
| Backend      | Node.js, Express.js                     |
| Database     | MongoDB                                 |
| AI Layer     | LangChain, OpenAI API                   |
| Auth         | JWT                                |
| Deployment   | Netlify (Frontend), Google Cloud (Backend)     |
